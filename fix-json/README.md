## Error Types It Fixes

| Error Category | Examples |
|---|---|
| **Missing/extra commas** | Trailing commas, missing commas between elements |
| **Unquoted keys** | `{name: "value"}` → `{"name": "value"}` |
| **Single quotes** | `{'key': 'val'}` → `{"key": "val"}` |
| **Unclosed brackets** | Missing `]`, `}`, or mismatched nesting |
| **Trailing content** | Extra characters after valid JSON ends |
| **Unescaped characters** | Raw newlines, tabs, or control chars in strings |
| **Comments** | `// line` and `/* block */` comment removal |
| **JavaScript literals** | `undefined`, `NaN`, `Infinity` → JSON equivalents |
| **Truncated data** | Incomplete JSON from copy-paste or API timeouts |
| **BOM markers** | UTF-8 BOM byte removal |

## How It Works

```
Input (broken JSON)
       │
       ▼
┌─────────────────────────┐
│  Layer 1: BOM/encoding  │  Strip byte-order marks, normalize encoding
│  Layer 2: Comments      │  Remove // and /* */ comments
│  Layer 3: Quotes        │  Fix single quotes → double quotes
│  Layer 4: Keys          │  Quote unquoted object keys
│  Layer 5: Values        │  Fix undefined/NaN/Infinity, trailing commas
│  Layer 6: Structure     │  Close unclosed brackets, fix nesting
│  Layer 7: AI Recovery   │  Pattern-match complex multi-error scenarios
└─────────────────────────┘
       │
       ▼
Output (valid JSON) ✓
```

Each layer runs independently - if your JSON only has quote issues, only layers 1–4 activate. The engine doesn't over-process clean data.

## Real-World Use Cases

- **API debugging** - Fix malformed responses from flaky endpoints before parsing
- **Log recovery** - Repair JSON extracted from application logs (often truncated or mixed with plaintext)
- **LLM output cleanup** - Fix JSON generated by AI models that add comments, trailing commas, or markdown fences
- **Copy-paste errors** - Recover JSON mangled by rich-text editors, Slack, or email clients
- **Config file repair** - Fix hand-edited JSON configs (package.json, tsconfig, etc.)
- **Legacy data migration** - Clean up JSONP, JavaScript object literals, or relaxed-JSON formats
