# Converter Hub — Transform JSON Between Formats

**Live tool:** [https://www.onlinejsonformatt.org/en/converter](https://www.onlinejsonformatt.org/en/converter)

A central page for all format conversion tools — move data between JSON, XML, CSV, YAML, POJO, and Dart class formats.

---

## Available Converters

| Conversion | Input | Output | Use Case |
|------------|-------|--------|----------|
| [JSON → XML](../json-to-xml/README.md) | JSON | Well-formed XML | Legacy system integration, SOAP APIs |
| [XML → JSON](../xml-to-json/README.md) | XML | Clean JSON | Modernizing XML workflows, REST migration |
| [JSON → CSV](../json-to-csv/README.md) | JSON array | Tabular CSV | Spreadsheets, data analysis, reporting |
| JSON → YAML | JSON | YAML | Kubernetes configs, Docker Compose, CI/CD |
| JSON → POJO | JSON | Java classes | Spring Boot, Android, type-safe models |
| JSON → Dart | JSON | Dart classes | Flutter apps, model generation |

## Common Workflows

### API Migration (XML → JSON)
```
Legacy SOAP API response (XML)
    → XML to JSON converter
    → Clean JSON for modern REST client
```

### Data Export (JSON → CSV)
```
API response with array of records (JSON)
    → JSON to CSV converter
    → Open in Excel/Google Sheets for analysis
```

### Config Translation (JSON → YAML)
```
package.json or tsconfig.json
    → JSON to YAML converter
    → Paste into docker-compose.yml or k8s manifests
```

### Type-Safe Models (JSON → POJO/Dart)
```
API response sample (JSON)
    → JSON to POJO or JSON to Dart
    → Generated class files ready for your project
```

---

## Privacy & Security

Every conversion runs in your browser. No data is uploaded to any server — safe for converting payloads that contain API keys, credentials, PII, or proprietary data structures.
