## Bug Reports & Feature Requests

Found a bug or have an idea for a new feature?

1. **GitHub Issues** (preferred) — File an issue on [github.com/onlinejsonformatt/ojf](https://github.com/onlinejsonformatt/ojf)
2. **Contact form** — Use the [web form](https://www.onlinejsonformatt.org/en/contact) if you don't have a GitHub account

When reporting a bug, include:
- Which tool/page the issue is on
- What you expected vs. what happened
- Browser and OS (Chrome/Firefox/Safari, Windows/Mac/Linux)
- A sample input (if safe to share) that reproduces the issue
