# About Online JSON Formatt

**Live page:** [https://www.onlinejsonformatt.org/en/about](https://www.onlinejsonformatt.org/en/about)

The story behind Online JSON Formatt — why we built a privacy-first developer toolkit and what makes it different.

---

## What We Built

Online JSON Formatt is a free, browser-based platform of 17+ developer tools for working with JSON, XML, and columnar data formats. It launched in August 2025 and serves developers in 6 languages across 20+ countries.

---

## Why We Built It

**The problem:** Most online JSON tools send your data to a remote server for processing. This means your API responses, config files, database exports — potentially containing secrets, tokens, and PII — are transmitted to a third party just to format or validate them.

**Our approach:** Every tool in the suite runs 100% in the browser. Your data never leaves your machine. We don't see it, store it, or log it.

---

## Core Principles

| Principle | What It Means |
|-----------|---------------|
| **Privacy by default** | All processing is client-side. No data upload, no server calls, no telemetry on input. |
| **Free forever** | No signup, no account, no rate limits, no premium tier. Sustained by unobtrusive ads. |
| **Developer-grade quality** | Monaco Editor (VS Code engine), not textarea hacks. Real IDE features in the browser. |
| **Multilingual access** | Full interface and content in EN, FR, ES, DE, RU, NL — not just translated buttons. |
| **Solve real problems** | AI-powered repair, large file handling, structural diff — features that address actual pain points. |
